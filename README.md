# INNOVATE | Ultra-Premium Futuristic Luxury E-Commerce

A fully working, luxury e-commerce web platform inspired by futuristic cyberpunk industrial design and Cupertino minimalism. Built with React 19, Tailwind CSS v4, Lucide Icons, HTML5 Canvas Particle Engine, and a dedicated Node.js Express backend API.

---

## ✨ Key Features

- **Exact Visual Parity Across All 9 Design Sections**:
  1. **Header & Hero Section**: Apple logo branding, frosted glass capsule navigation pill, dual CTA buttons (`Book it Now`, `Call To Action`), and an interactive floating 3D showcase with interactive hotspots.
  2. **Featured Collections**: 5 vertical frosted glass cards with bottom cyan neon glow bars and deep-dive exploration modals.
  3. **Best Selling Innovations**: 5 product showcase cards with prices, ratings, and instant `[+]` Add to Bag buttons.
  4. **Our Innovation Story**: Architectural executive visual, brand narrative, and 3 interactive metric cards (320+ Awards, 9.8M Innovators, 50+ R&D Centers).
  5. **Fifth Section (Core Values)**: 5 cards (Global Express, Elite Craft, Fortified Pay, Smooth Returns, Eternal Assist) wired to live modals.
  6. **Elite Innovator Reviews**: Testimonial carousel with next/previous controls and live review submission.
  7. **Limited-Time Offer**: Real-time ticking countdown timer (hours, minutes, seconds) and instant 40% OFF flash sale button.
  8. **Stay Ahead**: Futuristic newsletter subscription with email validation, confetti celebration, and promo code reward.
  9. **Footer & Payment Dock**: 4-column directory, contact links, and interactive payment dock with Visa, MasterCard, AMEX, PayPal, Apple Pay, and Bitcoin badges.

- **Full-Stack E-Commerce Engine**:
  - **Slide-In Cart Drawer**: Item quantity modifiers, item removal, promo code calculation (`INNOVATE20`, `CYBER40`, `VIP`), and checkout transition.
  - **Quantum Checkout Gateway**: Multi-method settlement supporting Apple Pay Biometric Passkey, Credit Card, PayPal, and Bitcoin Lightning QR.
  - **Supersonic Delivery Telemetry**: Live order tracking lookup (try `INV-8924` or your newly generated order ID) with a 5-stage real-time progress map.
  - **24/7 AI Luxury Concierge**: Live automated chat assistant for queries regarding shipping, materials, warranties, and allocations.
  - **Product Quick-View Modal**: Finish switcher (*Obsidian Cyber*, *Titanium Frost*, *Deep Space Blue*), specs, and warranty details.
  - **Live Product Search**: Instant keystroke search filtering across all collections and products.
  - **User Authentication**: Sign In / Sign Up modal with Apple ID passkey simulation and persistent user profile state.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8, Tailwind CSS v4, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express, CORS
- **Effects**: HTML5 Canvas Particle Engine, Specular Frosted Glassmorphism, CSS Perspective Cyber Grids

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ateebahmad22/ecommerce.git
cd ecommerce
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the Backend API Server
```bash
node server/server.js
```
*API runs at `http://127.0.0.1:5001`*

### 4. Start the Frontend Development Server
```bash
npm run dev
```
*App runs at `http://127.0.0.1:5173`*
